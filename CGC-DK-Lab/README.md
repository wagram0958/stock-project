# CGC-DK-Lab

目標：測試 DK 是否能在台灣大樂透 6/49 上，透過公開資料與可重現模型，提高未來正式凍結樣本的平均命中數 K。

主要指標：每期命中數 K 與累積平均 K。
公平基準：E[K] = 36/49 = 0.7346938776。

## 每期閉環

官方歷史資料
→ DK 候選研究
→ 唯一一組 6 號
→ Gate 0
→ 正式凍結
→ 保存快照
→ 官方開獎
→ 對答案
→ K / 6-K
→ 累積統計
→ 模型修正
→ 新版只適用未來期

## 核心原則

- 每期只允許一組正式預測。
- 正式凍結後禁止改號。
- 沒有開獎前凍結證據的號碼，不補登為正式前瞻樣本。
- 歷史回測只作探索與模型篩選。
- 真正成效只看未來正式凍結樣本。
- 20 / 50 期只做描述；預設 100 個有效未來期做第一批正式評估。
